# Mayday - Assets/Sounds Folder

This folder contains all the audio assets (SFX and BGM) for the game **Mayday**.

## Audio File Requirements
If you download the recommended files or use your own custom sounds, make sure they are named exactly as listed below and are in the correct format (`.wav` for SFX, `.ogg` or `.mp3` for BGM):

- `jump.wav` - Player jump sound
- `light_attack.wav` - Player light attack slash sound
- `heavy_attack.wav` - Player heavy attack swing/impact sound
- `player_damage.wav` - Player taking damage grunt/hit sound
- `enemy_damage.wav` - Enemy taking damage hit sound
- `monkey_attack.wav` - Monkey screech/attack sound
- `bird_attack.wav` - Bird screech/swoop sound
- `checkpoint.wav` - Checkpoint activation chime
- `beacon.wav` - Beacon energy beam/victory sound
- `bgm.ogg` - Sci-fi / Jungle suspense background music (BGM)

The game has been fully integrated with safe audio fallbacks. If any file is missing, the game will run perfectly in silent mode for that specific sound.
